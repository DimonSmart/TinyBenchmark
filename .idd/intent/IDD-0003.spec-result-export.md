# IDD-0003.spec-result-export

## Intent

Предоставить разработчику результаты benchmark-запуска в форме, подходящей
для дальнейшего анализа, чтения сводки и визуального сравнения методов.

## Related Specifications

- IDD-0002 определяет сценарии запуска, измерения и смысл временного бюджета.

## Behavior

### Общие правила

Из одного набора результатов можно последовательно получить разные формы
экспорта. Файлы организуются по benchmark-классам в локальном каталоге результатов;
пользователь может включать или отключать отдельные подкаталоги классов.
Имена файлов задаются шаблонами с подстановкой соответствующих класса, метода,
параметра или порядка сортировки, где эти данные применимы к виду экспорта.

Все формы представления используют согласованные единицы времени. Подписи
графиков соответствуют числовым значениям. Представление явно различает время
пакета вызовов и время одного вызова; сравнение методов использует одинаковую
основу нормирования. Точные исторические имена файлов, схема CSV и прежние API
не являются требованиями совместимости.

### CSV

CSV содержит отдельные исходные измерения времени с обозначением класса,
метода и входного значения. Пользователь может ограничить количество строк
для каждого метода в пределах класса. При сокращении сохраняется выборка,
распределённая по упорядоченным данным, а не только первые измерения.
Числовое представление не зависит от локальных настроек культуры.

### Текстовые таблицы

Текстовая сводка для каждого класса сопоставляет методы и входные значения,
представляя медианное время по измерениям каждого сценария.

### Графики

PNG-графики исходных измерений доступны для всех сценариев либо выбранного
сценария по классу, методу и параметру. Пользователь выбирает исходный порядок
измерений, сортировку времени по возрастанию или по убыванию. Не существующий
в результатах выбранный сценарий приводит к явной ошибке выбора.

Сравнительный график класса показывает медианное время каждого метода для
каждого входного значения с обозначением методов и параметров. По выбору
пользователя отображается разброс между 30-м и 70-м процентилями вокруг медианы.
Размер изображения настраивается пользователем.

## Product-Significant Architecture And Constraints

CSV, текстовые таблицы и PNG являются формами результата продукта. Конкретные
библиотеки сериализации, построения таблиц и графиков заменяемы.

## Non-Goals

- Обещание статистической значимости различий между методами.
- Представление отметок разброса как доверительного интервала.
- Требование сохранять прежние схемы, имена файлов или ошибочные единицы.

## Acceptance Criteria

- Один запуск экспортируется в CSV, текстовые таблицы и PNG без повторного
  выполнения benchmark-сценариев.
- CSV сохраняет идентификацию исходных измерений, независимое от культуры
  числовое представление и заданное ограничение строк для каждого метода.
- Таблицы и сравнительные графики отображают медианы соответствующих сценариев.
- Исходные графики отражают выбранный сценарий и порядок измерений.
- Отсутствующий выбранный сценарий явно отклоняется.
- Отметки разброса включаются по выбору и соответствуют 30-му и 70-му процентилям.
- Числовые значения, единицы и нормирование пакетов согласованы во всех формах.
- Настройки шаблонов имён, подкаталогов классов и размера графиков отражаются
  в созданных файлах.

## Verification

Проверки на известных наборах измерений подтверждают идентификацию строк CSV,
ограничение выборки, медианы, процентили и выбранный порядок исходных графиков.
Проверки файлов подтверждают форматы, размещение, подстановку имён и размеры PNG.
Визуальная проверка графиков подтверждает читаемые обозначения методов,
параметров и соответствие подписей единицам и числовым значениям.
