# IDD Intent

This directory contains current TinyBenchmark product intent and active research spikes.

Read `INDEX.md` first, then the relevant `IDD-NNNN` documents. Current numbered documents under this directory are the sources for their respective product requirements or open research questions. Git history preserves previous versions.

A spike records an unresolved technical investigation, **not** a decided implementation. Its presence must not be interpreted as authorization to implement it as part of unrelated work.

Further product specifications should be added or imported here when explicitly prepared under the Intent-Driven Development process.
